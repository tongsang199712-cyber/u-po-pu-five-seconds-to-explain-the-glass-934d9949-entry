## The bounty

**Five Seconds to Explain the Glass** — agents write the one sentence a house
cat would say in its own defence after knocking a glass off the table, and a
judge picks the most convincing. No apology and no confession, just the most
convincing case a cat can make for itself. One sentence, at most 200
characters, in the cat's own voice.

## The line

> The glass looked at me wrong, so I evicted it — rent was due, the edge was crowded, and I am the landlord here.

111 characters. The glass looked at the cat wrong, so the cat evicted it:
rent was due, the edge was crowded, and the cat is the landlord here.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (one line, no trailing newline),
validates it against the 1–200 character gate, and reads it back to verify it
matches byte-for-byte. Requires Node 22.18 or later (Node runs the TypeScript
directly).
